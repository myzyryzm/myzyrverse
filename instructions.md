Technical Specification: ASOIAF-Style Multi-Agent Novel Writing System (LangGraph)

System Overview

Build a stateful, multi-agent novel writing engine using LangGraph. The system architecture is a Hub-and-Spoke (Orchestrator-Workers) pattern modeled after George R.R. Martin's "Gardener" writing style. The story will be written in the same POV style. It merges pre-defined world lore with historical RAG research (e.g., Bronze Age Collapse, Harem Conspiracy) and character psychological archetypes. It features automated AI critique loops and three distinct Human-in-the-Loop (HITL) interrupt gates to allow the author to edit state and adjust lore mid-flight.

1. Graph State Schema & Architecture

Define a TypedDict state schema named MyzyrverseState with the following structures:

Core State Fields:

• master_lore (Dict): Protected Core Canon containing immutable world facts, faction profiles, and magic systems. Accessible by AI nodes but mutable only by the user during HITL gates.
• palace_factions (Dict[str, List[str]]): Map of character names to political factions or conspiracy cells.
• next_steps (Union[str, List[str]]): The control string/list evaluated by the conditional router.
• review_status (str): Enum tracking workflow phases ('PENDING_RESEARCH_REVIEW', 'PENDING_OUTLINE_REVIEW', 'PENDING_FINAL_REVIEW', 'APPROVED').
• revision_count (int): Counter tracking the internal AI critique loop (hard cap at 3 to prevent infinite loops).
• historical_analogues_active (List[str]): Context strings populated by the Historian node.
• sentiment_guidelines (List[str]): Narrative friction rules injected by the Psychologist node.
• current_chapter_outline (str): Detailed beat-sheet created by the Weaver node.
• draft_prose (str): Raw prose text generated by the Maester Writer.
• critique_notes (str): Feedback logs generated by the Grand Critic.

3. Braking Mechanisms: Compile the graph using interrupt_before=["human_gate_research", "human_gate_outline", "human_gate_final"].

4. Worker Node Specifications

- All will be run using the claude agent sdk set up (to leverage claude code)
  A. The Maestro (The Orchestrator)

• Evaluates current state step-by-step.
• If research is missing \(\rightarrow \) fires parallel research nodes.
• If review_status == 'PENDING_RESEARCH_REVIEW' \(\rightarrow \) routes to human_gate_research.
• If research passes \(\rightarrow \) deploys weaver.
• If outline is built \(\rightarrow \) routes to human_gate_outline.
• If outline passes \(\rightarrow \) deploys maester_writer.
• If prose is drafted \(\rightarrow \) deploys grand_critic.
• The Loop Logic: If critique_notes == 'FAILED' and revision_count < 3, clear draft_prose, clear critique_notes, increment revision_count by 1, and immediately re-route back to maester_writer. If count hits 3, force escalate to human_gate_final.

B. The Historian Node

• Prompting Style: Systemic Collapse expert. Emphasizes logistics, infrastructure breakdown, and historical coup mechanics (e.g., Judicial Papyrus of Turin, corrupt officials, the impact of localized droughts on trade lines). Avoids medieval/feudal tropes.

C. The Psychologist Node

• Prompting Style: Grimdark character architect. Strips away clean "good vs. evil" binary. Forces characters to act out of existential panic, survival instincts, or conflicting obligations (e.g., choosing between an unfit legitimate heir and an ambitious, capable usurper).

D. The Weaver Node

• Combines the approved historical context, psychological friction points, and master lore into a scene-by-scene beat sheet.

E. The Maester Writer Node (Local CLI Hook)

• Requirement: Must execute an LLM call via a Python subprocess command rather than a standard web API wrapper, allowing the author to leverage their local terminal CLI subscription.
• Implementation Strategy: Wrap the system instructions, outline, and lore context into a prompt string. Send the prompt to the CLI process, read from standard output (stdout), strip terminal formatting/loading indicators, and return the clean prose back into draft_prose.

F. The Grand Critic Node

• Evaluates prose strictly against stylistic goals: grounded bronze age terminology (e.g., chariots, bronze sickle-swords, god-kings, scribe-bureaucrats—no "knights" or "chivalry"). im aiming for complex characters (morally grey eg jamie lannister; villain who actually might be the anti hero eg al swearengen, etc).
